バイナリヘクスエディタ

あらゆるファイル(画像・動画・実行ファイル・テキストなど)をブラウザ上で開いて、16進 / ASCII で直接編集できます。すべてローカル処理で、ファイルは外部に送信されません。

※ ウィンドウにファイルをドラッグ&ドロップしても開けます。Chrome / Edge では「保存」すると、開いたファイルそのものを書き換えることができます。

バイトをクリックその場で編集(2桁16進 or 1文字)。16進文字を直接入力でも可
矢印キー / PgUp・PgDnカーソル移動
Shift + クリック / 矢印範囲選択
Delete / Backspace選択範囲(または1バイト)を削除
F3 / Shift+F3次 / 前の一致へ(ツールバーの検索欄使用)
比較… / F62つ目のファイルを読み込み、異なるバイトを赤く表示。F6 で差分間を移動
破損診断PNG/JPEG/ZIP などの構造を検査し、破損個所を推定(比較ファイルがあれば差分と対応付け)
Ctrl + Z / Y元に戻す / やり直す
Ctrl + C / X / Vコピー(16進テキスト) / 切り取り / 貼り付け
Ctrl + S保存(File System API 非対応時はダウンロード)
